3. INSTALLATION AND HOW TO USE
================================================================================
  1. Read "6.LICENSE AGREEMENT" below and agree the terms and conditions. 
  2. Unpack the ZIP file to the folder you want to install the program.
  3. Execute 'SHARP Calculator' to start program.
    - Now it can use as of the simulator.

  * If the calculator need to RESET, select recycling icon (Reset) from
    menu by pressing green triangle '>' on the right of [ON/C].

 <Screen capture>
  1. Run the program.
  2. Display an image to be captured.
  3. Select camera icon (Capture) from option menu by pressing
     green triangle '>' on the right of [ON/C].
    - Screen is now saved to 'Image' folder in the folder created by unpacking.

  * Screen captured image in 'Image' folder will be over written, so that any
    necessary image should be moved to another folder before executing a program.

================================================================================

5. KNOWN ANOMALIES
================================================================================
* If you have problems running the Simulator, disable any virus checking 
  software you may be running.

<Operation differences from EL-W506/W516/W546>
 1. Cannot change contrast.
 2. Does not turn off automatically.
 3. Less variety in number of Random function (including R-DICE, R-COIN, and 
    R-INT) and question of the drill function. 
 4. Cursor does not blink.
 5. Any value stored in memory will be cleared when the application is closed.
